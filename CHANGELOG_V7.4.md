# V7.4 Change Summary

- Batch Add page for up to 20 personnel at a time.
- Fixed custom qualification/certification preservation on member edits.
- Private member Documents & Certifications library with upload, preview, edit, delete, issue/expiry dates, source, verification status, external-system metadata, external record ID, and external link.
- Future-integration-ready fields for systems such as Vector Solutions; no external service is connected in V7.4.
- Public Red Card status with PIN-protected full-card viewing using one-view/short-lived access behavior.
- Apparatus NFC URLs send signed-in users directly to the apparatus's active Wildland deployment.
- Deployment Forms workspace for CTR/SF-261, OF-288, and OF-286.
- All fields exposed by the V7.4 form editor can be changed before preview; changes are document-only and do not alter source member/apparatus/deployment records.
- Preview before final save.
- Versioned PDF output stored only with its deployment.
- Audit events for generated, opened, and overridden deployment forms.
- V7.3 fixes retained: Engine Boss Wildland redirect, Engine Boss management of any active deployment, and correction of completed timesheet entries while deployment is active.
